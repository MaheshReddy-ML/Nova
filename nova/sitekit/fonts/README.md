# Bundled fonts

Website concepts embed these fonts locally, so concept pages need no network access.
All families are licensed under the SIL Open Font License 1.1 (see OFL.txt; each family's copyright is held by its authors):
Fraunces (Undercase Type), Inter (Rasmus Andersson), Instrument Serif (Instrument), Manrope (Mikhail Sharanda),
Space Grotesk (Florian Karsten). Files are the Latin subsets published by Fontsource (@fontsource/*@5.1.0).
